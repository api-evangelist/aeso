# AESO — Alberta Electric System Operator

> The independent, not-for-profit system and market operator for Alberta's electricity system. AESO
> dispatches generation, operates the Alberta Interconnected Electric System, plans transmission, and
> runs Alberta's energy-only wholesale market including Pool Price settlement. It publishes fourteen
> JSON market-data APIs through an Azure API Management gateway, plus a fully anonymous legacy CSV
> report surface. Authentication is a single API-KEY header; keys are self-serve and free. Use of
> AESO material is restricted by its site terms to non-commercial, personal or educational purposes.

## Authentication

- Send your subscription key as the `API-KEY` request header, or as the `subscription-key` query parameter.
- Anonymous calls return HTTP 401 `{"statusCode": 401, "message": "Access denied due to missing subscription key..."}`.
- Base URL pattern: `https://apimgw.aeso.ca/public/{api}/{version}{path}` (secondary host `gateway-apim.aeso.ca`).

## APIs

- [Pool Price Report](https://developer-apim.aeso.ca/api-details#api=poolprice-api-v1-1): hourly Alberta Pool Price, forecast pool price and 30-day rolling average for a date range back to 2000-01-01 (max one year per request). `GET /price/poolPrice`
- [System Marginal Price Report](https://developer-apim.aeso.ca/api-details#api=systemmarginalprice-api-v1-1): the real-time price signal that sets the pool price, as a range report and as a current value. `GET /price/systemMarginalPrice`, `GET /price/systemMarginalPrice/current`
- [Current Supply Demand v2](https://developer-apim.aeso.ca/api-details#api=currentsupplydemand-api-v2): Alberta Total Net Generation, Net Actual Interchange, Alberta Internal Load, contingency reserve and generation mix by fuel type. `GET /csd/summary/current`
- [Current Supply Demand v1](https://developer-apim.aeso.ca/api-details#api=currentsupplydemand-api-v1): per-asset current generation. `GET /csd/generation/assets/current`
- [Actual Forecast Report](https://developer-apim.aeso.ca/api-details#api=actualforecast-api-v1): actual and forecast Alberta Internal Load for a date range. `GET /load/albertaInternalLoad`
- [AIES Gen Capacity](https://developer-apim.aeso.ca/api-details#api=aiesgencapacity-api-v1): generation capacity and generator outages submitted to AESO. `GET /AIESGenCapacity`
- [Load Outage Forecast](https://developer-apim.aeso.ca/api-details#api=loadoutageforecast-api-v1): load outages submitted to AESO. `GET /loadOutageReport`
- [Intertie Public Reports](https://developer-apim.aeso.ca/api-details#api=itc-api-v1): intertie interchange capability and flow, and intertie outages. `GET /interchange`, `GET /outage`
- [Energy Merit Order Report](https://developer-apim.aeso.ca/api-details#api=energymeritorder-api-v1): the stacked offers that determine dispatch and where price clears. `GET /meritOrder/energy`
- [Metered Volume Report](https://developer-apim.aeso.ca/api-details#api=meteredvolume-api-v1): settlement-grade metered volumes at market-asset granularity. `GET /meteredvolume/details`
- [Operating Reserve Offer Control Report](https://developer-apim.aeso.ca/api-details#api=operatingreserveoffercontrol-api-v1): who controls offers for Alberta's ancillary-services reserve products. `GET /operatingReserveOfferControl`
- [Asset List](https://developer-apim.aeso.ca/api-details#api=assetlist-api-v1): the registry of market assets — the reference data behind every asset_ID in every other feed. `GET /assetlist`
- [Pool Participant](https://developer-apim.aeso.ca/api-details#api=poolparticipant-api-v1): the market-participant registry behind the asset list. `GET /poolparticipantlist`
- [Unit Commitment Data v2](https://developer-apim.aeso.ca/api-details#api=unitcommitmentdata-api-v2): unit commitment directives issued by AESO. `GET /unitCommitment`

## Anonymous CSV surface (no key required)

- [Market and System Reporting](https://www.aeso.ca/market/market-and-system-reporting/): the ETS report index.
- `http://ets.aeso.ca/ets_web/ip/Market/Reports/CSDReportServlet` — Current Supply Demand
- `http://ets.aeso.ca/ets_web/ip/Market/Reports/SMPriceReportServlet` — hourly Pool Price / System Marginal Price
- `http://ets.aeso.ca/ets_web/ip/Market/Reports/DailyAveragePoolPriceReportServlet` — daily on-peak / off-peak averages
- Append `contentType=csv` for machine-readable CSV. No key, no account, no licence click-through.
